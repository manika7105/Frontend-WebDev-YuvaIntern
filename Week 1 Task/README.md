# DevSpace — Week 1 Static Web Page

A responsive developer portfolio landing page created for the **Frontend Web Developer Internship — Week 1 Task: Transforming Wireframes into Static Web Pages**.

## Task Context

The internship instructions required converting a provided wireframe into a functional static webpage. No wireframe was supplied with the task, so an original design concept was created instead. The design was intentionally structured to demonstrate semantic HTML, organized CSS, responsive behavior, visual hierarchy, and attention to spacing and typography.

## Features

- Semantic HTML5 structure
- Responsive navigation
- Hero section with developer-focused visual
- About section
- Skills cards
- Project cards
- Contact call-to-action
- Responsive layouts for desktop, tablet, and mobile
- Hover and keyboard focus states
- Reduced-motion accessibility support
- CSS custom properties for consistent design values
- Google Fonts for typography

## Technologies

- HTML5
- CSS3
- CSS Media Queries
- CSS Custom Properties
- Google Fonts

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Resize the browser window or use developer tools to test responsive breakpoints.

## Responsive Strategy

The layout uses CSS Grid and Flexbox for the main sections. At narrower widths, multi-column layouts collapse into one or two columns. Navigation is allowed to wrap on mobile, and typography and spacing scale down to maintain readability.

## Design Note

Because no official wireframe was provided, the final interface should be considered an original interpretation of the task rather than a pixel-for-pixel recreation of an external mockup.
